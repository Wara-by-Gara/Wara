## 2. 인증/인가 엣지케이스

- [ ] 만료된 JWT → 401 테스트
- [ ] 위조된 JWT → 401 테스트
- [ ] state 없는 OAuth callback → 401 테스트
- [ ] 차단된 유저의 리소스 접근 → 403 테스트
- [ ] 참가자가 아닌 유저의 접근 → 403 테스트
- [ ] HOST 전용 엔드포인트에 GUEST 접근 → 403 테스트

---

## 3. 리소스 접근 엣지케이스

- [ ] 존재하지 않는 ID 조회 → 404 테스트
- [ ] 다른 초대장 리소스 ID로 접근(IDOR) → 404 테스트
- [ ] 삭제(deletedAt)된 리소스 조회 → 404 테스트

---

## 4. 상태 기반 접근 엣지케이스

- [ ] 마감(closed)된 초대장 참가 → 422 테스트
- [ ] absent RSVP 상태에서 금지된 작업 → 403 테스트
- [ ] 비활성화된 미션 템플릿 사용 → 400 테스트

---

## 5. 중복 / 동시 요청 엣지케이스

- [ ] 이미 참가한 초대장 재참가 → 409 테스트
- [ ] 이미 좋아요한 사진 좋아요 → 409 테스트
- [ ] DB unique constraint가 동시 요청을 한 번만 허용하는지 테스트

---

## 6. 입력값 검증 엣지케이스

- [ ] 필수 필드 누락 요청 → 400 테스트
- [ ] 잘못된 ULID 형식 path param → 400 테스트
- [ ] 허용되지 않는 추가 필드 포함 요청 → 400 테스트
- [ ] 경계값(빈 문자열, 최대 길이 초과 등) 테스트
