## 목적
사용자가 소셜 계정 1개로 즉시 가입/로그인할 수 있도록 한다. 초대장 링크를 통해 진입한 경우 초대 컨텍스트를 노출.

## 접근 권한
- 비로그인 사용자 전용 (이미 로그인된 경우 홈으로 자동 redirect)

## 상태 다이어그램
```
default → kakao/naver/apple Loading → (성공: 가입 or 홈) | failed | cancelled
       → withInvitationContext → 동일 분기
       → sessionExpiredModal (이전 세션 만료 안내)
       → loginRequiredBottomSheet (다른 화면에서 호출 시)
       → accountBlocked / withdrawnAccount (정책 차단)
```
