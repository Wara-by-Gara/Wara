## 목적
앱을 처음 띄울 때 보이는 화면. 자동 로그인 시도, 네트워크/서버 상태 확인, 새 버전 안내를 담당합니다.

## 접근 권한
모든 사용자 (인증 없음).

## 상태 다이어그램
```
default → autoLoginLoading → (성공: 홈) | (실패: autoLoginFailed)
       → networkError → 재시도
       → serverMaintenance (점검 안내)
       → updateRequired / forceUpdate (강제) | optionalUpdate (선택)
```
