```
start → templateCategory/list/preview/selected | blankTemplate
     → basicInfo (제목·설명·이미지)
     → dateTime
     → location
     → rsvpSetting (정원·동반인·질문)

     → design (레이아웃·색·폰트·스티커)
     → preview → publishConfirm → publishingLoading → publishComplete
```
