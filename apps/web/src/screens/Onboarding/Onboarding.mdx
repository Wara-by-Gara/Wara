## 목적
신규 사용자에게 Wara 서비스를 소개하고, 알림·사진·위치 권한을 사전에 안내합니다 (OS 권한 팝업 직전에 이유 설명).

## 접근 권한
- First Visit (한 번도 본 적 없는 사용자)
- 이후 진입 시 자동 스킵 → `/login` 또는 `/`

## 상태 다이어그램
```
intro1 → intro2 → intro3 → intro4 → intro5 (Start CTA)
   ↓ skip 누르면
skipModal (확인 후 종료)
   ↓
permissionNotification → permissionPhoto → permissionLocation
   ↓ 허용/거부
completedRedirect (홈으로)
```
