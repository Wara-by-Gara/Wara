## 개요
Wara는 한 화면에 **기능 아이콘** 과 **장식 아이콘** 을 섞어 사용하지 않습니다.

- **기능 아이콘** — `lucide-react` outline 스타일, 24px 기본, stroke 2px
- **장식 아이콘** — Wara 전용 픽셀/스티커 SVG, 감성 표현 전용
- **소셜 로고** — 카카오·네이버·애플 공식 브랜드 컬러 고정 (`color` prop 무시)

전체 75개 아이콘이 카테고리별로 정리되어 있어요.

---

## 사용법

```tsx
import { Icon } from "@/components/icons";

<Icon name="home" size="md" color="primary" aria-label="홈" />
<Icon name="send" size="xl" color="primary" decorative />
<Icon name="kakao-logo" size="lg" aria-label="카카오로 로그인" />
```

| Prop | 타입 | 기본값 | 설명 |
|---|---|---|---|
| `name` | `IconName` | — | 아이콘 이름 (kebab-case) |
| `size` | `xs(12) \| sm(16) \| md(20) \| lg(24) \| xl(32) \| number` | `"md"` | 픽셀 크기 |
| `color` | `default \| primary \| inactive \| danger \| success \| inverse \| currentColor` | `"default"` | 색상 토큰 |
| `strokeWidth` | `number` | `2` | Lucide stroke 두께 |
| `decorative` | `boolean` | `false` | true면 `aria-hidden`, false면 `aria-label` 필요 |
| `aria-label` | `string` | — | 의미 있는 아이콘은 필수 |

- `default` → `gray-700`
- `primary` → `pink-500` (CTA, 선택)
- `inactive` → `gray-300` (비활성)
- `danger` → `red-500` (삭제·신고)
- `success` → `green-500` (완료)
- `inverse` → `white` (어두운 배경 위)

## 규칙

> ICONS.md §1.2 · §2.1 발췌

- 한 프로젝트 안에서 **outline / filled / 픽셀** 스타일을 섞지 않기
- stroke 2px 통일, 탭바·앱바는 24px 기본
- 작은 텍스트 옆 아이콘은 16px
- Empty State 아이콘은 32~48px
- 터치 영역 최소 44×44px (IconButton에서 보장)
- 장식 아이콘과 기능 아이콘은 같은 행에 섞어 쓰지 않음
- 소셜 로고는 항상 공식 브랜드 컬러 (color prop 무시)
- `decorative={true}` 시 `aria-hidden`, 그 외에는 `aria-label` 필수
