# Wara 컬러 시스템

DESIGN.md §4 기준 — 화이트 기반 + 파스텔 포인트 + 레트로 강조색.

- **Primary Pink** → 주요 CTA, 선택된 RSVP, 핵심 배지, 활성 탭
- **Sky Blue** → 정보성 배지, 지도/장소, 보조 버튼, 공유 피드백
- **Yellow** → D-day, 이벤트 포인트, 스티커
- **Red** → 삭제, 신고, 나가기, 오류 (위험 액션 전용)

> 한 화면에서 강한 포인트 컬러는 **최대 2개**까지만.
