# Wara 타이포그래피

DESIGN.md §5 기준. 기본 폰트는 **Pretendard**, 로고/이벤트 강조에만 픽셀 폰트(**DungGeunMo / Galmuri**)를 제한적으로 사용합니다.

**규칙**
- 본문 텍스트 최소 **14px**
- 한 화면에서 폰트 크기는 **4단계 이하**
- 픽셀 폰트는 긴 본문 금지 — 로고/짧은 제목/배지/장식 문구에만
