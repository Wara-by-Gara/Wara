# Wara Spacing Scale

DESIGN.md §6 기준 — **4px 베이스** 스케일.

| 토큰 | 값 | 주요 사용처 |
|---|---:|---|
| `--space-1` | 4px | 미세 정렬 |
| `--space-2` | 8px | 리스트 아이템 간격 |
| `--space-3` | 12px | 입력 필드 간격, 카드 간격 |
| `--space-4` | 16px | 카드 내부 padding, 좁은 좌우 padding |
| `--space-5` | 20px | 화면 좌우 padding 기본 |
| `--space-6` | 24px | 하단 CTA와 콘텐츠 간격 |
| `--space-8` | 32px | 섹션 간 간격 |
| `--space-10` | 40px | – |
| `--space-12` | 48px | – |
| `--space-16` | 64px | 큰 구역 분리 |

## 화면 밀도 규칙 (DESIGN.md §6.2)

- 모바일 화면에서는 세로 여백을 너무 크게 잡지 않는다.
- 첫 화면에서 핵심 CTA가 보이도록 한다.
- 초대장 상세 화면은 감성을 위해 여백을 넉넉히 써도 된다.
- 참석자 명단·댓글·알림은 정보 밀도가 중요하므로 여백을 줄인다.
